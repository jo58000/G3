Mode de relevé

Si la case n'est pas cochée, renseigne séparément la danse et le dévers de chaque file. Le dévers réel utilisé dans les calculs est dévers lu + danse.

Résultats G3 – méthode en diagonale

Fenêtre glissante de 6 traverses (base de 3 m), décalée d'une traverse à chaque calcul. Rouge = file G au début + file D à la fin ; bleu = file D au début + file G à la fin. G3 = bleu − rouge, signe conservé.

Calcul Ed – base de 10 m

Pour chaque point central B, le calcul utilise les points A et C situés à 5 m de part et d'autre : Ed = |dB − (dA + dC) / 2|. Le signe de l'écart avant valeur absolue indique la nature : négatif = trou, positif = bosse. Les valeurs sont traitées indépendamment pour chaque file. Les points sont interpolés linéairement à partir des PK saisis.
